Features

为什么是 NexusCLI

不是一个空壳 Demo：核心路径有测试覆盖，经过本地 smoke 与真实终端运行验证，文档里的每个「支持」都能在真实入口运行。

🧭

Plan-and-Execute

独立 Planner 生成任务 DAG，按依赖批次并行执行；图级 checkpoint 默认开启，/plan --resume 跨进程续跑，协作式中断不打断已完成批次。

🤖

Multi-Agent 协作

Planner / Worker / Reviewer 分工，依赖调度与并行 worker，review 不通过自动重试；子代理可用 task 工具后台委派并经文件邮箱互通消息。

🔌

MCP 双向

既能作为 client 连接 stdio / Streamable HTTP server（带 allowed_tools 过滤），也能把自身内置工具暴露为 MCP server 供其他 Agent 使用。

🧠

记忆与压缩

静态项目记忆 + SQLite 动态长期记忆（去重、TTL、相关性召回）；上下文达预算 80% 自动压缩旧轮次，/compact 随时手动压缩并指定保留重点。

📸

快照与恢复

Agent run 前后自动快照，支持恢复现场；vfs_ls / vfs_read 把历史快照挂载为只读虚拟文件系统，改前改后对比无需回滚工作区。

🪝

Hooks · Skills · 插件

七个生命周期事件挂 shell 钩子；builtin/user/project 三层 Skill 体系 + HITL 确认的技能沉淀；本地插件目录可注入代理、Skill 与斜杠命令。

🔐

权限与安全

allow / deny / ask 三组规则在 HITL 之前自动放行、追问或拦截；写文件后自动语法诊断，危险动作经 policy、HITL 与 audit 全链路处理。

📡

Runtime API

serve --http 把线程、turn、事件流与后台任务暴露为带鉴权的 HTTP API，外部系统可以直接接入 Agent 能力。

🧪

离线评测回归

nexuscli eval 用脚本化假 LLM 驱动真实 Agent 跑 JSON 场景，两次运行自动 diff，regression 计数可直接当 CI 门禁。

Modes

三种运行模式

同一套工具与权限体系，三种推进方式。会话中按 Shift+Tab 还可在 Default / Auto / plan 之间循环切换权限态。

⚡ React 默认

经典 ReAct 工具调用循环：thinking → tool call → result → final，带循环调用检测与回合预算，交互 REPL 与单次 -p 均可用。

📋 Plan 先规划

先由 Planner 拆解为依赖 DAG，再按批次并行执行；checkpoint 跨进程续跑，适合多步骤改造、审计与迁移类任务。

👥 Team 协作

Planner + 多 Worker + Reviewer 全链路协作，review 重试直至通过，也可把 worker 切到 plan 模式承接更重的并行任务。
